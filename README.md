# 🏨 DOWNTOWN VILLA v2

> Futuristic media search & management bot for Telegram.

## ✨ Features

- 🔎 **Search engine** — multi-shard, cached, color-coded progress bars
- 📚 **Indexing** — auto + manual (full scan, ordered, crash-safe)
- 💾 **Backup** — smart resume, auto-rotate, multi-target
- 🎬 **Series group** — 6-step flow with PM delivery via deep links
- 💎 **Premium watch** — watched list, next episode, watch order, badges
- 📢 **Broadcast** — channels / groups / users / both
- 📅 **OTT** — weekly releases, trending, spotlight, hype, recommendations
- 🔍 **Missing finder** — TMDB gap scanner with editable templates
- 👥 **Group admin** — 14 sections, everything customizable from Telegram
- 📝 **Requests** — request channel with admin action buttons
- 📋 **Log channel** — every event tracked
- 🎛️ **Admin panel** — one command, live dashboard
